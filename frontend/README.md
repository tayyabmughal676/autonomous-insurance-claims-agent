# Data Daur — Frontend Application

High-density Linear / Stripe style enterprise claims adjuster workbench built with React 18, TypeScript, Tailwind CSS v4, and Bun.

## Quickstart

### 1. Install dependencies with `bun`
```bash
bun install
```

### 2. Run Development Server
```bash
bun run dev --port 5173
```

### 3. Run Linters & Production Build
```bash
bun run lint
bun run build
```
